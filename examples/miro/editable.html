LOCAL DEVELOPMENT PANEL · EDITABLE PROFILE

Native-preserving Miro round trip

A small synthetic flow exercises the new editable-network adapter: create mapped objects, read semantic edits back into UMF, then patch UMF-owned text without resetting native layout or style.

Writes are explicit. Export creates new objects on the current board. Capture only reads. Update writes source-owned fields to existing mapped objects. This panel never deletes objects or retries/rolls back interrupted native writes.

3 · Preserve and updateChange the UMF question and update. Native position/style should remain intact.
