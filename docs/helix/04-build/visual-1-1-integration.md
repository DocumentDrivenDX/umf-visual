# Versioned review integration

2026-10-29 (America/New_York). Implements the review carried by PR #4 against
[FEAT-034](../01-frame/features/FEAT-034-visual-vocabulary.md),
[US-093](../01-frame/user-stories/US-093-visual-vocabulary.md),
[CONTRACT-083](../02-design/contracts/CONTRACT-083-visual-vocabulary.md) and
[TD-093](../02-design/technical-designs/TD-093-visual-vocabulary.md).

Package v0.1.0 shipped before this review merged. Consequently the corrections
are explicit vocabulary 1.1.0, planned in package 0.2.0; this integration does not
publish a release. Released schema and manifest bytes live under
`spec/extensions/visual/1.0.0/`. The released semantic validator is retained as
`src/extensions/visual/legacy-1-0.ts`, changing only its manifest import path.
Regression hashes fence these assets and all imported fixture/source bytes.

Default creation, `VISUAL_VERSION`, `visualPackage`, `./schema`, `./manifest` and
native import remain 1.0.0. Registering both validators selects semantics from the
declared version. `LATEST_VISUAL_VERSION`, `latestVisualPackage`,
`./schema/1.1.0`, `./manifest/1.1.0` and the third create argument expose 1.1.0.
`upgradeVisualDocument` copies and validates the target declaration, refusing
invalid target semantics without modifying the input. Generated public types are
a 1.1.0 superset; they do not imply runtime interpretation under an older version.

The review corrects years 0000–0099, admits up to 500 nodes with split advice
above fifteen, adds exact multiplicities and entity-scoped stable field ids, and
generates the latest manifest schema and TypeScript shapes from the authored
schema. Native adapters retain their own subset and size limits. Unknown native
mappings remain losses or refusals, including exact multiplicities and field ids.

`tests/visual/versioning.test.ts` verifies frozen bytes, independent version
behavior, explicit upgrade, native limits and located losses. The retained-source
fixture was generated by executing the published v0.1.0 tag's source against the
pinned public SDK. It must replay unchanged; relabeling its document 1.1.0 must
refuse exact original recovery. Existing inventory fixtures remain 1.0.0.

See the integration check results in PR #4 for the final combined branch. Native
replay and browser checks qualify only the documented subsets; no every-form or
full-fidelity native support is claimed by these fixes.
