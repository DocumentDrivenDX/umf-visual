SEMANTIC PRODUCER→umf.visual→NATIVE TARGETS

umf.visual is a typed authoring target for semantic producers and an interchange model for native tools. This catalogue shows initial, bounded DOT, Mermaid, and Lini profiles; reported loss may signal a model gap or an unfinished mapping.
